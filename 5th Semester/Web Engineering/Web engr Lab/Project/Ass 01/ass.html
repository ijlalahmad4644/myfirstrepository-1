Table Border Styles

Dotted Dashed Solid Double
Groove Ridge Inset Outset
None Hidden Solid Double

Explanation of Border Styles:

  • Dotted: A border consisting of small dots.
  • Dashed: A border made up of short dashes.
  • Solid: A single, unbroken line.
  • Double: Two solid lines with space in between.
  • Groove: A 3D-styled border that appears carved.
  • Ridge: A 3D-styled border that looks raised.
  • Inset: Makes the element appear embedded into the page.
  • Outset: Gives the element a raised appearance.
  • None: No border is displayed.
  • Hidden: Similar to 'none' but may affect table layout in certain cases.
