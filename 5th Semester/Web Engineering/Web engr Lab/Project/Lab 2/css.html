CSS (Cascading Style Sheets) is a styling language used to control the presentation of HTML elements. It allows developers to define colors, fonts, spacing, alignment, layouts, and responsiveness. CSS can be applied in three ways: Inline CSS – Applied directly within an HTML element using the style attribute. Internal CSS – Defined within a tag inside the head section of an HTML document. External CSS – Written in a separate .css file and linked to an HTML document using the link tag.
